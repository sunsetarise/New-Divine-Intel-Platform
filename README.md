# 🔬 Engineering Principles

### 1. Evidence over marketing

A feature name is not proof of implementation.

### 2. Reproducibility over opaque success

Important outputs should be reconstructable.

### 3. Measured performance over claimed performance

Hardware/backend claims require actual execution.

### 4. Human review over automated certainty

Analytical systems provide evidence and structured findings—not automatic guilt, identity, intent or institutional decisions.

### 5. Non-destructive lineage

Major upgrades are designed to preserve validated prior capabilities unless a stronger compatible implementation replaces them.

### 6. Failure is data

Non-convergence, missing dependencies, insufficient evidence and unavailable hardware are valid explicit states.
